# Practica 2 - Investigacion de ecosistemas de construccion de software

La practica consiste en investigar diferentes ecosistemas de construccion de software y determinar para cada uno:

- Alcance.
- Utilidad.
- Limites.
- Aplicacion.

Ecosistemas a investigar:

1. Ecosistema basico Python moderno:
   - Git.
   - GitHub.
   - pytest.
   - Ruff.
   - Black.
   - GitHub Actions.

2. Ecosistema de calidad de codigo:
   - pytest.
   - coverage.py.
   - Ruff.
   - mypy.
   - SonarQube.

3. Ecosistema CI/CD:
   - GitHub Actions.
   - GitLab CI.
   - Jenkins.

4. Ecosistema de seguridad y mantenimiento:
   - pip-audit.
   - Dependabot.
   - Renovate.
   - Snyk.

5. Ecosistema de empaquetado y entornos Python:
   - Poetry.
   - pip-tools.
   - tox.
   - nox.
   - build.

6. Ecosistema de documentacion tecnica:
   - MkDocs.
   - Sphinx.
   - pdoc.
   - GitHub Pages.

7. Ecosistema DevSecOps minimo:
   - GitHub.
   - GitHub Actions.
   - pytest.
   - Ruff.
   - pip-audit.
   - Dependabot.
