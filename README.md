## Practicas

- Se crea el repositorio base para el curso.

### Practica 1 - Refactorizar el codigo

El grupo debe crear una version mejorada del codigo.

Requisitos minimos:

- Separar calculo de impresion.
- Evitar depender directamente de `datetime.now()`.
- Crear funciones pequenas.
- Usar nombres claros.
- Permitir pruebas unitarias.
- Mantener las mismas reglas de negocio.
